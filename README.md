# Funny Virals 2.0

Orin is the voice aide for Funny Virals 2.0. Open it on a phone or tablet, or link two screens with a code.

What it does on the device, without a paid call:

- Tasks, notes, and remembered facts (including a phone number you can call or text after you tap)
- Timers and reminders while the page is open
- A morning briefing, math, percentages, and unit conversions
- Saved places and map handoff
- Calls, texts, WhatsApp, ChatGPT, Claude, YouTube, Instagram, and mail. Nothing sends until you tap.

The reel desk turns a prompt into a vertical storyboard, optional 10-second clips, one music bed, and a downloadable master. Pictures and video use the xAI key in the server environment (`XAI_API_KEY`). Do not commit that key.

`templates/` is the original 1080×1350 slide pack.

## Run

```bash
npm install
npm run dev
```

The dev server listens on port 8080.
